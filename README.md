# Household Income and Expenditure Analysis

## 📌 Project Overview

This project analyzes household income and expenditure patterns to understand how income levels, expenditure, regions, and sources of income are related.

The project uses **Python, SQL, and Power BI** to perform data cleaning, exploratory data analysis, SQL-based analysis, and interactive dashboard visualization.

## 🎯 Objectives

* Analyze household income and expenditure patterns
* Identify important factors affecting household expenditure
* Compare income and expenditure across different regions
* Analyze different sources of household income
* Perform data cleaning and exploratory data analysis
* Create an interactive Power BI dashboard
* Generate meaningful business insights from the data
